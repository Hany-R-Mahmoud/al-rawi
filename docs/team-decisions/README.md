# Team Decisions

This directory is the durable home for agreements that affect architecture,
product behavior, APIs, workflows, or project conventions.

## Belongs here

- architecture and persistence decisions
- API and security-boundary decisions
- product or UX behavior that should remain stable
- workflow and team conventions
- deprecations and migrations

## Does not belong here

- temporary chat or brainstorming
- personal notes
- duplicated issue-tracker content

## How to record a decision

1. Add a row to [`decision-log.md`](decision-log.md) for a small agreement.
2. Copy [`decision-template.md`](decision-template.md) for a larger decision.
3. Use `Proposed`, `Accepted`, `Superseded`, or `Deprecated` consistently.
4. Link the affected source and documentation.

No historical decision records were present before this documentation bootstrap.
